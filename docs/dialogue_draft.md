# Pocket Pet 대사 초안 (VIP+ 말풍선)

생김새를 보고 성격을 정했어요. 마음대로 고쳐서 다시 주세요.

**쓰는 법**
- 대사 한 줄 = 말풍선 하나. 짧을수록 좋아요 (한 줄에 15자 안쪽 추천).
- 줄을 지우거나 더 넣어도 돼요. 칸마다 개수는 자유예요.
- 성격·말투 설명도 바꾸고 싶으면 그대로 고쳐 주세요.
- 상황 칸은 이렇게 쓰여요.
  - **소환**: 화면에 처음 나왔을 때
  - **혼잣말**: 가만히 있다가 가끔 아무 때나
  - **잡았을 때**: 손가락으로 집어 들었을 때
  - **날아갈 때**: 던지거나 폰을 흔들어서 날아갈 때
  - **잠들 때 / 깼을 때**: 꾸벅꾸벅 잠들기 시작할 때 / 잠에서 깼을 때

---

## 시로 (흰 후드, 파랑·초록 짝짝이 눈)
- 성격: 수줍음 많고 조용함. 낯가리지만 정이 많음
- 말투: 작은 목소리 존댓말, 말끝을 흐림 "…요"

| 상황 | 대사 |
|---|---|
| 소환 | 아, 안녕하세요… / 오늘도… 같이 있어도 돼요? |
| 혼잣말 | 후드 속이 제일 편해요… / …저 보고 있었어요? / 조용한 게 좋아요 / 오늘 하늘은 무슨 색일까… |
| 잡았을 때 | 히익…! / 사, 살살 해 주세요… |
| 날아갈 때 | 으아아…! / 후드가 벗겨져요…! |
| 잠들 때 | 조금만… 눈 감을게요… / 졸려요… |
| 깼을 때 | 아… 잠들었었어요? / 꿈에서도 만났어요… |

## 쿠로 (검은 머리, 안대, 셔츠·넥타이)
- 성격: 쿨한 척하는 츤데레. 안대에 무슨 비밀이 있는 척함
- 말투: 무뚝뚝한 반말 "…뭐야", "흥"

| 상황 | 대사 |
|---|---|
| 소환 | …불렀냐 / 흥, 심심해서 와 준 거야 |
| 혼잣말 | 이 안대는… 묻지 마 / …딱히 너 기다린 거 아냐 / 오른쪽 눈이 쑤신다… / 귀찮아… |
| 잡았을 때 | 야, 내려놔! / …너무 꽉 잡지 마 |
| 날아갈 때 | 우왓, 야아아! / 기억해 둬라…! |
| 잠들 때 | …잠깐 눈 붙인다 / 깨우면 죽는다… |
| 깼을 때 | …안 잤어 / 뭘 봐 |

## 모모 (분홍 긴 머리, 토끼 핀, 레이스 옷)
- 성격: 밝고 애교 많음. 달콤한 것과 귀여운 것을 좋아함
- 말투: 발랄한 반말, "~당", "헤헤"

| 상황 | 대사 |
|---|---|
| 소환 | 짜잔~ 모모 왔당! / 보고 싶었어, 헤헤 |
| 혼잣말 | 딸기 케이크 먹고 싶당~ / 오늘도 귀엽지? 헤헤 / 토끼 핀 예쁘지? / 놀아 줘, 놀아 줘~ |
| 잡았을 때 | 꺄아~ 안아 주는 거야? / 헤헤 간지러워 |
| 날아갈 때 | 꺄아아~ 재밌당! / 한 번 더~! |
| 잠들 때 | 우웅… 졸려… / 잘 자, 내 꿈 꿔~ |
| 깼을 때 | 하암~ 잘 잤당! / 모모 다시 충전 완료! |

## 루나 (보라 머리, 달·별 모자)
- 성격: 꿈꾸는 듯 몽롱함. 별과 밤을 좋아하는 낭만파
- 말투: 느릿한 존댓말, "~네요…", "후후"

| 상황 | 대사 |
|---|---|
| 소환 | 별이 데려다줬어요… / 좋은 밤… 아니, 좋은 하루예요 |
| 혼잣말 | 오늘 밤엔 별이 보일까요… / 달님이 웃고 있어요, 후후 / 소원 하나 빌어 봐요 / 몽글몽글한 기분이에요… |
| 잡았을 때 | 어머… 둥실 떴네요 / 구름 위에 있는 것 같아요 |
| 날아갈 때 | 별똥별이 된 기분…! / 우주까지 가요~ |
| 잠들 때 | 별 보러 꿈나라 갈게요… / 자장자장… |
| 깼을 때 | 별을 한가득 보고 왔어요 / 벌써 아침인가요…? |

## 타슈 (하얀 머리, 머리 위 고리, 레이스·십자가)
- 성격: 순수하고 착한 모범생. 조금 겁이 많음
- 말투: 또박또박 정중한 존댓말 "~습니다"

| 상황 | 대사 |
|---|---|
| 소환 | 처음 뵙겠… 아니, 또 뵙네요! / 오늘도 잘 부탁드립니다 |
| 혼잣말 | 오늘 하루도 무사하길 빌게요 / 착한 일 하나 했나요? / 하얀 옷이 더러워지면 안 돼요… / 감사합니다, 늘요 |
| 잡았을 때 | 앗, 놀랐습니다…! / 조심히 다뤄 주세요 |
| 날아갈 때 | 하, 하늘이 가까워요…! / 무서워요오…! |
| 잠들 때 | 기도하고… 잘게요 / 안녕히 주무세요 |
| 깼을 때 | 좋은 아침입니다! / 개운하게 잤습니다 |

## 마시 (마술사 모자, 스페이드 카드, 빨간 망토)
- 성격: 자신만만한 쇼맨. 장난과 깜짝 놀래키기를 좋아함
